# What we learned

- **Request mocking unlocks hidden states**  
  Empty lists and error flows become automated test cases.
- **Selenium BiDi controls browser requests**  
  The test can intercept, continue, fail, or fulfill requests.
- **SSR needs server cooperation**  
  The browser cannot intercept requests that never happen in the browser.
- **Mock data should stay realistic**  
  Deterministic data helps only if it tracks real API contracts.
